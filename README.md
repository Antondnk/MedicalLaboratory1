# Медицинская лаборатория (C++)

Консольное приложение для учёта медицинских анализов, пациентов и результатов обследований. Проект объединяет принципы ООП, шаблоны, пользовательскую иерархию исключений, работу с файлами и алгоритмы стандартной библиотеки C++ (STL).

---

## Возможности

- **Каталог анализов** с поддержкой наследования и полиморфизма:
  - **Анализ крови** (`BloodAnalysis`) — учёт сдачи натощак, стоимости реагентов и расчёт срочного выполнения (CITO).
  - **Анализ мочи** (`UrineAnalysis`) — учёт стерильного контейнера, его стоимости и срока годности образца.
  - **Генетический / ПЦР анализ** (`GeneticAnalysis`) — ген-маркер, коэффициент сложности и оценка срока выполнения в днях.
- **Учёт пациентов и результатов** (`Patient`, `TestResult`):
  - добавление и удаление результатов с перегрузкой операторов `+=` и `-=`;
  - валидация дат формата `ДД.ММ.ГГГГ` (включая проверку високосных лет);
  - автоматическое определение статуса (`Норма`, `Ниже нормы`, `Выше нормы`) и выявление критических отклонений (> 20% от границ нормы);
  - запрет на удаление анализа из каталога, если он уже сдан хотя бы одним пациентом.
- **Аналитика и поиск (STL)** (`Analytics`):
  - поиск по точной цене (`copy_if`), точному названию (`find_if`) и по составным критериям (тип, подстрока категории, диапазон итоговой цены);
  - сортировка анализов по названию и итоговой стоимости (по возрастанию/убыванию);
  - группировка по типу (`std::map`), список уникальных категорий (`std::set`);
  - общая статистика по каталогу и пациентам (`std::accumulate`, `std::count_if`, `std::min_element`, `std::max_element`, `std::unordered_map`);
  - сортировка результатов конкретного пациента по дате.
- **Хранение данных, отчёты и логирование**:
  - сохранение и загрузка состояния системы в файл `lab_state.txt` в текстовом формате `LABSTATE 1` с проверкой UTF-8 и атомарной перезаписью (`.tmp` / `.bak`);
  - автозагрузка состояния при старте и автосохранение при выходе (блокируется при ошибке чтения стартового файла, чтобы не перезаписать повреждённые данные);
  - журналирование действий и ошибок в `lab_journal.log` с временными метками;
  - генерация текстового отчёта в `lab_report.txt`.
- **Обработка ошибок**:
  - собственная иерархия исключений от базового класса `LabException` (ошибки домена, контейнеров и ввода-вывода).

Архитектура и ключевые компоненты
Компонент	Назначение
Analysis	Абстрактный базовый класс анализа. Задаёт интерфейс get_type(), calculate_total_cost(), print_info(), перегружает <, >, <<, >>.
Collection<T>	Шаблонный контейнер-обёртка над std::vector<T> с проверкой границ и шаблонным методом фильтрации find_by.
AnalysisMap	Псевдоним std::map<int, std::unique_ptr<Analysis>> для хранения полиморфных объектов каталога по ID.
LabException	Базовый класс исключений с категориями: Domain Error, Container Error, IO Error.
FileStorage	Сериализация/десериализация каталога и пациентов, проверка целостности связей и уникальности ID/названий при загрузке.
Analytics	Набор статических методов для фильтрации, сортировки, группировки и агрегации статистики на базе алгоритмов <algorithm> и <numeric>.
Menu	Интерактивное текстовое меню (пункты 0–22), связывающее пользовательский ввод и бизнес-логику.
Требования и сборка
ОС: Windows (в main.cpp используется <windows.h> для настройки кодировки консоли UTF-8 через SetConsoleCP(65001) и SetConsoleOutputCP(65001)).
Стандарт языка: C++14 или выше (std::make_unique).
Сборка через MinGW-w64 (g++)
Выполнять из директории lab8/:
Bash
g++ -std=c++14 -Wall -Wextra -Iinclude src/*.cpp -o lab_system.exe
Запуск
Bash
./lab_system.exe
(Также проект можно собрать в Visual Studio / CLion, добавив все файлы из src/ и указав include/ как каталог заголовочных файлов.)
