# Medical Laboratory Management System (Lab #4)

Консольное приложение на языке C++, разработанное в рамках лабораторной работы №4 по дисциплине **«Программирование на языках высокого уровня»**. Проект моделирует работу медицинской лаборатории с упором на ключевые принципы объектно-ориентированного программирования: **абстракцию, наследование и динамический полиморфизм**.

---

## 🧪 Архитектура и ключевые особенности

Программа построена на основе иерархии классов для управления различными типами лабораторных исследований:

1. **Абстрактный базовый класс `Analysis`**:
   * Задает единый интерфейс для всех видов анализов.
   * Содержит чисто виртуальные методы: `get_type()` и `calculate_total_cost()`.
   * Реализует полиморфное сравнение объектов (`>` и `<`) на основе итоговой стоимости.
   * Оснащен **виртуальным деструктором** (`virtual ~Analysis() = default;`) для корректного освобождения динамической памяти через базовый указатель.

2. **Производные классы (дочерние)**:
   * **`BloodAnalysis`** (Анализ крови): учитывает требования к сдаче натощак и стоимость реагентов, реализует расчет экспресс-стоимости (`calculate_express_cost()`).
   * **`UrineAnalysis`** (Анализ мочи): учитывает использование стерильного контейнера и рассчитывает максимальный срок годности биоматериала (`get_max_sample_validity_hours()`).
   * **`GeneticAnalysis`** (Генетический/ПЦР анализ): использует ген-маркер и коэффициент технологической сложности для оценки сроков выполнения (`estimate_processing_days()`).

3. **Система управления (`Menu` и `Patient`)**:
   * Хранение коллекции анализов в виде вектора указателей базового класса (`std::vector<Analysis*>`).
   * Безопасное приведение типов с использованием **`dynamic_cast`** для доступа к специфической бизнес-логике дочерних классов.
   * Управление базой пациентов и ведение истории сданных тестов.
