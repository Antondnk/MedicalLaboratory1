# Лабораторная работа №1
**Вариант 9:** Медицинская лаборатория.

## Описание
Программа моделирует работу медицинской лаборатории. 
Реализованы классы для хранения видов анализов, результатов тестов и пациентов. 
Присутствует проверка бизнес-логики: пациент не может сдать один и тот же анализ дважды в один день.
