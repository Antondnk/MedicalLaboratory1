# Лабораторная работа №1
**Вариант 9:** Медицинская лаборатория.

Консольное приложение на C++ для автоматизации работы медицинской лаборатории. Программа позволяет управлять базой анализов и вести медицинские карты пациентов.

## 🌟 Основные возможности

- **Управление анализами:** просмотр списка, добавление новых видов анализов, изменение стоимости и сравнение цен.
- **Карта пациента:** добавление сданных анализов, просмотр истории и удаление записей.
- **Проверка правил (бизнес-логика):**
  - Защита от повторной сдачи одного и того же анализа в одну дату.
  - Автоматическое выявление критических отклонений от нормы.
  - Валидация корректности ввода даты (формат `ДД.ММ.ГГГГ`).

## 🛠️ Используемые механизмы C++

В проекте продемонстрированы следующие возможности C++:
- **Перегрузка операторов:**
  - `>` и `<` — сравнение анализов по стоимости.
  - `==` — проверка совпадения анализа и даты.
  - `+=` и `-=` — добавление и удаление результатов из карты пациента.
  - `<<` и `>>` — удобный ввод и вывод объектов через поток.
- **Дружественная функция (`friend`):** `is_critical()` для оценки результатов анализа без нарушения инкапсуляции.

## 📂 Структура проекта

- `Analysis.h` / `Analysis.cpp` — класс вида анализа (название, цена, нормы).
- `TestResult.h` / `TestResult.cpp` — класс результата теста (дата, значение, статус).
- `Patient.h` / `Patient.cpp` — класс пациента (история анализов).
- `Menu.h` / `Menu.cpp` — логика консольного меню.
- `main.cpp` — точка входа.
